## Resolution

No lawyer is engaged. The open points were reviewed from public sources (not legal advice), and the contribution model was changed so the remaining questions no longer arise (see the revised decision on "Decide license and contribution model (ADR 0.1)"):

- **Derivative work, same-process use:** no German case law on linking; irrelevant as long as the maintainer owns all AGPL code the private repo uses (the copyright holder is not bound by their own license).
- **Corresponding Source for a hosted stack:** irrelevant for the same reason.
- **CLA wording for Germany:** dropped; no CLA. The "Linux clause" (§ 32 (3) sentence 3 UrhG) does not cover an exclusive grant to one party, so remuneration claims (§§ 32, 32a) could remain; avoided by not merging external code.
- **DCO as a license basis:** it is not one (attests origin only); not needed.
- **§ 7 exception:** replaced by putting the plugin SDK under Apache-2.0.

**Remaining premise to keep true:** the maintainer holds all rights to the code. Before the hosted offering, confirm that rights to all past commits lie with the maintainer, and commit only as a private person from now on. Tracked by the maintainer, outside this map.
