## Resolution

- **Ports with contracts:** `BlobStore`, `SecretStore`, `Extractor`, the ones an embedder realistically implements itself. The others reuse the default adapters; adding a contract later is a minor change. `JobQueue` gets none (pg-boss and the port are to be removed, see the review on "Decide Composition Root as library (1.1)").
- **Package:** new `packages/port-contracts`, vitest as `peerDependency` (`application` may not depend on vitest). Part of the public library API from 1.9, with its own `api.txt`.
- **Shape:** vitest-bound functions, e.g. `describeBlobStoreContract(name, setup)`; `setup` returns a store and a cleanup. No runner-agnostic variant.
- **Default adapters run the same suites:** `FileBlobStore` and `EnvelopeSecretStore` (on PGlite). Single tests that only cover the general behaviour are dropped; adapter-specific ones stay (e.g. path traversal in `FileBlobStore`). `EnvelopeSecretStore` gets its first direct test this way.
- **Test doubles exported** from the same package: `InMemoryBlobStore`, `InMemorySecretStore`, `ScriptedExtractor`, `FakeClock` (moved from `apps/api/test/support`), each passing the suites. `FakeTextExtractor`, `ScriptedIdentityProvider`, `FakeTessdataCatalog` stay internal.
- **Instance separation is a contract case:** `setup` is called twice for two Instance-scoped stores; for `SecretStore` and `BlobStore`, `list`/`get`/`remove` of one never see the other's entries (required for `SecretStore` because of the secret sweep).
- **Extractor contract:** for Extractors that talk to an OpenAI-compatible endpoint. The package exports the stub server (today in `openai-compatible-extractor.test.ts`); the suite checks: valid answer → Events/Tasks; 401/403 → `unauthorized`; not reachable → `unreachable`; schema mismatch or cut off → `invalid-output`; never throws; `health()` and `models()` against the stub as well. A hosted quota wrapper around `OpenAiCompatibleExtractor` passes while the quota allows.
- **Quota exhausted:** no new problem kind; reported as `unreachable` with an explaining `message`. Retry via the backoff (review on "Decide worker as due-work functions (1.3)").
- **SemVer:** the contract is the ports' doc comments. A case that tightens it (a conforming adapter may now fail) is major; a case covering already documented behaviour, a new suite or a new double is minor.
